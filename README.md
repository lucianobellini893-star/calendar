# Мои встречи

Статический календарь на русском: встречи, дата, время, описание, редактирование, удаление и напоминания. Без установки зависимостей и без сборки.

## Vercel

Импортируйте этот репозиторий в Vercel. Framework Preset: Other. Root Directory: корень репозитория. Build Command: без команды. Output Directory: `.`. Сервер, база данных, переменные среды и ключи не нужны.

Локальный запуск: `python3 -m http.server 8000 --bind 127.0.0.1` из корня репозитория.

Данные хранятся в localStorage текущего браузера и не синхронизируются между устройствами. Напоминания требуют открытой вкладки; сон компьютера и фоновые ограничения браузера могут задержать их. Для системных уведомлений разрешите их по кнопке. Все даты, часы встреч и напоминания используют Europe/Rome независимо от часового пояса устройства. Зимнее/летнее время учитывается автоматически. Несуществующее время при весеннем переводе часов отклоняется; при осеннем повторе часа выбирается первое вхождение. Старые записи сохраняют свои дату и часы, теперь интерпретируемые как итальянское время. Пропущенные напоминания показываются в течение часа после начала встречи. Сайт не может закрепить окно поверх всех приложений Windows. Для закрепления окна можно использовать Windows PowerToys Always On Top (Win+Ctrl+T).

Резервная копия скачивается кнопкой; автоматического импорта пока нет. Не очищайте данные браузера без копии. Одновременное редактирование в нескольких вкладках не поддерживается.

Проверка часового пояса: `node tests/timezone.cjs`. Тесты охватывают зимнее и летнее время Италии, переходы часов, неверные даты и смену даты в Риме.
